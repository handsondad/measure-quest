# 📏 度量衡奇遇记（MeasureQuest）

给 5–12 岁孩子的测量科普网站，奇遇记系列（[汉字奇遇记](https://handsondad.github.io/hanverse/)、[身体奇遇记](https://handsondad.github.io/bodyverse/)）的一员。

小念（7 岁的男孩）碰到一件和测量有关的事——量桌子数字打架、一分钟为什么是 60 秒、美国说今天 77 度——就去问爸爸。爸爸回答，小念接着爸爸的话追问，6 轮一路讲到道理，最后小念用自己的话总结。

每个问题都有三样东西讲同一件事：

- **问答**：一问一答的对话，图解步骤穿插其中；
- **讲解动画**：每轮问答一场戏，尺子、天平、钟面、温度计、卫星在画面上一步步长出来，小念和爸爸的配音把整段对话读出来，动画跟着声音走；
- **动手实验室**：嵌在对话里、也能单独打开的小实验——一拃一拃量桌子、天平称水果、60 颗糖分给好朋友、摄氏华氏两把温度尺子、三颗卫星找小念、给东西挑尺子（千米到纳米）、当一回电表。

## 内容

30 个问题，分在三组 12 个主题里：

| 主题 | 问题 |
|---|---|
| **🧭 测量从哪里来** | |
| 🤝 为什么要量 | 量桌子 8 拃还是 5 拃？秤不准会怎样？火星气候探测器的单位事故 |
| 🏯 中国的度量衡 | 度·量·衡三个字、秦始皇统一度量衡、半斤八两、三尺布和市制 |
| 🌍 世界各地的单位 | 英尺是国王的脚吗？英里、公里、海里哪个最长 |
| **🧩 七个基本量** | |
| 🧱 七块积木和词头 | 全世界一共有几把“尺子”？千米、厘米、毫米前面那个字 |
| 📏 长度 · 米 | 一米是谁定的？为什么用光来定？光年是时间还是长度 |
| ⚖️ 质量 · 千克 | 天平怎么知道一样重？被换掉的“大K”、到了月球会变轻吗 |
| ⏰ 时间 · 秒 | 一分钟为什么是 60 秒？一秒是谁定的 |
| 🌡️ 温度 · 开尔文 | 温度计的原理、摄氏度和华氏度、绝对零度 |
| ⚡ 电流 · 安培 | 充电器上的 2A、电费单上的一度电 |
| 💡 发光强度 · 坎德拉 | 灯有多亮、在多亮的地方看书 |
| 🫘 物质的量 · 摩尔 | 一口水里有多少水分子、一斤绿豆和一斤黄豆哪个颗数多 |
| **🚀 今天的测量** | |
| 🛰️ 今天的测量 | 手机定位、芯片里的纳米 |

除了一个个问题，还有几张把测量串起来的总览页：

- **🧩 单位大家庭**（`#/units`）：7 个基本单位，度·量·衡和今天的单位怎么对上，导出单位是哪几块积木拼的，从昆到亏的词头表，市制和英制换算；每个基本单位还有一页档案（`#/unit/metre` 等）。
- **🗓️ 大事年表**（`#/timeline`）：从古埃及肘尺、秦统一度量衡、《米制公约》，到 2019 年 7 个单位全交给自然常数。
- **📚 资料库**（`#/sources`）：国际和国家计量机构、我国计量制度文件、博物馆藏品、好读的文章和书。

事实优先取自 BIPM、NIST、国务院文件、国家博物馆等机构资料；每个问题页尾的「给大人」写了背景、精确数字和出处。

## 开发

需要 Node.js 22.18+（测试和脚本直接用 Node 跑 `.ts`）。

```bash
npm install
npm run dev          # 开发服务器
npm test             # 问答规则、动画规则、配音、时间线
npm run build        # 生产构建，输出到 dist/
npm run voice        # 用 edge-tts 给新的或改过的句子配音（要联网、python -m pip install edge-tts、ffmpeg）
```

写新问题、新动画之前，先读 [AGENTS.md](AGENTS.md) 和 [skills/measurequest-explainer/SKILL.md](skills/measurequest-explainer/SKILL.md)。

`docs/` 是早期版本的产品设计文档和资料清单，保留作参考。第三方素材和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

推到 `main` 后，GitHub Actions 会跑测试并部署到 GitHub Pages。
